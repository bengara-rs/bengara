# 定期処理

決まった間隔で動かしたい処理を書く場所です。

> **自動では動きません。** `cargo artisan schedule:run` を **1 分ごとに外から呼ぶ前提**です。
> cron やタスクスケジューラに登録してください。常駐する仕組みはありません。
> Laravel と同じ形です。

```text
* * * * * cd /path/to/app && ./myapp schedule:run >> /dev/null 2>&1
```

Windows ならタスクスケジューラで、1 分おきに `myapp.exe schedule:run` を登録します。

## 書く

`routes/console.rs` に書きます。`init` が雛形を作ります。
クロージャは `Result<()>` を返します。登録は書いた順です。

```rust
//! routes/console.rs
use bengara::prelude::*;

pub fn schedule(s: &mut Schedule) {
    s.job("再設定トークンの掃除", Every::Hour, || async {
        PasswordReset::sweep_expired().await.map(|_| ())
    });

    s.job("記事数の集計", Every::Minutes(5), || async {
        let total = crate::app::models::Post::count().await?;
        Cache::forever("stats.posts", total.to_string()).await
    });
}
```

## 間隔

| `Every`      | 間隔                                       |
|--------------|--------------------------------------------|
| `Minute`     | 呼ばれるたびに動かす（1 分ごとに呼ぶ前提） |
| `Minutes(n)` | n 分ごと                                   |
| `Hour`       | 1 時間ごと                                 |
| `Day`        | 1 日ごと                                   |
| `Seconds(n)` | n 秒ごと                                   |

- **「毎週月曜の 3 時」のような指定はできません。** cron の式は読みません。
- **名前は重ねられません。** 同じ名前を 2 回 `job` に渡すと、起動時にパニックします。
  名前は「前回いつ動いたか」を覚える鍵です。
- **名前を変えると、別の処理として数え直します。**

## 動かす

```sh
cargo artisan schedule:run
```

```
  再設定トークンの掃除 成功（9 ms）
  記事数の集計 成功（2 ms）
2 件動かしました。
```

一覧だけ見たいときは `schedule:list` です。

```
名前                  間隔        前回
再設定トークンの掃除  1 時間ごと  2026-10-05 10:17:21
記事数の集計          5 分ごと    2026-10-05 10:17:21

2 件
```

### 失敗とパニック

| 起きること     | どうなるか                                                         |
|----------------|--------------------------------------------------------------------|
| `Err` を返した | `名前 失敗: 理由` と出て、**残りのタスクは動く**                   |
| パニックした   | `名前 失敗: 処理がパニックしました` と出て、**残りのタスクは動く** |

どちらでも、時刻は動かす前に書いてあるので次の 1 分で繰り返し走りません。
パニックはそのタスクの中に閉じ込めます。`schedule:run` 全体は落ちません。

### 二重に走らない

**タスクごとに錠ファイルを取ります。** 守るのは「動かすかどうかの判定」だけです。
2 つの `schedule:run` が同時に来ても、同じ時刻に動かすと決めるのは 1 つだけです。
2 台が同じ `storage/` を共有しているときも同じです。

**ただし「同じ処理が 2 回走らない」とまでは言えません。** 間隔が来ていれば、
どちらの `schedule:run` でも動きます。1 つの処理が間隔より長くかかると、
次の回に始まった分と並んで動きます。

**長くかかる処理は [キュー](queue.md) に積んでください。**
Laravel の `withoutOverlapping` に当たるものはありません。

錠が取れなかったタスクは `名前 は飛ばします（錠を取れませんでした）` と出て動きません。
ほかのタスクは動きます。

## 中で何をするか

`schedule:run` は本体のバイナリなので、アプリの中身を全部使えます。

```rust
s.job("古い記事を消す", Every::Day, || async {
    DB::table("posts").where_op("created_at", "<", "2020-01-01 00:00:00").delete().await?;
    Ok(())
});

s.job("お知らせを積む", Every::Hour, || async {
    Queue::push_raw("SendReport", "{}").await?;
    Ok(())
});
```

## 前回の時刻の置き場所

最後に動かした時刻は **`storage/framework/schedule/` のファイル**に置きます。
1 つの処理が 1 つのファイルで、ファイル名は名前をハッシュにしたものです。

- **`CACHE_DRIVER` が何であっても間隔は正しく効きます。** `cache:clear` でも消えません。
  やり直したいときは `storage/framework/schedule/` の中を消してください。
- ディレクトリは `schedule:run` が無ければ自分で作ります
  （`cargo artisan storage:init` も作ります）。権限は所有者だけに絞ります（Unix で 0700）。
- **`storage/` そのものが無いときだけ止まります。**「`storage/` を作ってください」と
  言って終わります。

## 間隔の数え方（触りません）

内部の決まりです。**ふだんは気にしなくて構いません。**

| こと                                    | 決まり                                           |
|-----------------------------------------|--------------------------------------------------|
| 時刻を書くとき                          | 動かす**前**に書きます（二重に走らないため）     |
| 失敗したとき                            | 次の間隔まで待ちます                             |
| 間隔が 1 分以上のタスク                 | **30 秒早くても動きます**（cron の遅れを許すため） |
| `Every::Seconds(n)` と 1 分未満         | 許容なし。時刻も秒のまま記録します               |
| 間隔が 60 秒以上のタスクの記録          | **分の頭に丸めます**（先行タスクの時間を積まないため） |
| 判定に使う時刻                          | 丸めません。タスクごとに取り直します             |
| 前回の時刻がいまより後だったとき        | 警告を出して動かします（時計が飛んだとき用）     |
| 錠を握る長さ                            | 「前回の時刻を読む → 判定する → 書く」の間だけ    |
| 錠の置き場所                            | `storage/framework/schedule/+locks/`             |
| 書き込み                                | 一時ファイルに書いて置き換えます                 |

## 無いもの

cron の式（`0 3 * * 1`）と時間帯の指定（`at('3:00')`）はありません。`Every` を使います。
常駐する `schedule:work` もありません。cron から `schedule:run` を呼びます。
長い処理の重なりの防止（`withoutOverlapping`）はありません。キューに積んでください。
ほかにまだ無いものは [backlog.md](backlog.md) にまとめてあります。
