# まだ無いもの

**まだ無い機能と、知っておくべき制限は、このページだけに書きます。**
いま使えるものは [README.md](README.md) の各ページにあります。

| 節                   | 中身                                         |
|----------------------|----------------------------------------------|
| まだ無いもの         | これから作るかもしれないもの                 |
| 直っていない不ぞろい | 動きがそろっていない所。直す予定のもの       |
| 直さないと決めた制限 | 直せるが、直さないと決めたもの               |
| 作らないと決めたもの | これからも作らないもの                       |
| 確かめていない環境   | まだ動かして確かめていない OS とデータベース |

## まだ無いもの

### ルートとミドルウェア

| 項目 | いまどうなるか | 代わりにすること |
|------|----------------|------------------|
| `Route::any` / `match` / `options` | 書けるのは 5 つのメソッドだけ | メソッドごとに 1 行ずつ書く |
| パス引数の後ろの固定文字（`/posts/{id}.json`） | 登録できない | `/posts/{id}/json` と区切る |
| 1 区間に 2 つのパス引数（`/{year}-{month}`） | 登録できない | `/{year}/{month}` に分ける |
| サブドメインでの振り分け | 照合するのはパスだけ | 前段のプロキシで振り分ける |
| ミドルウェアへの引数（`throttle:60,1`） | 渡せるのは名前だけ | 設定済みのものを別名で登録する |
| ミドルウェアの優先順の指定 | 登録した順と書いた順に通る | 並べる順で調整する |
| 既定で入るミドルウェアの組（Laravel の `web`） | 無い | `bootstrap/app.rs` に自分で並べる |
| ミドルウェアから内側のエラーの中身を見る | 見えるのは出来上がったレスポンスだけ | ステータスで見分ける |
| ルートの一覧をテストから取る | 取る口が無い | `route:list --json` の出力を読む |

### リクエストとレスポンス

| 項目 | いまどうなるか | 代わりにすること |
|------|----------------|------------------|
| アップロードの受け取り（multipart） | 無い | 本文をそのまま受けて保存する |
| 大きなファイルを少しずつ返す | 全部をメモリに読んでから返す | 前段のプロキシで配る |
| 途中からの取得（`Range`）と `Last-Modified` | 無い。`ETag` と `304` はある | 同上 |
| 圧縮済みファイル（gzip / brotli） | 無い | 前段のプロキシで圧縮する |
| 接続の待ち時間と同時接続数の上限 | 無い | 前段のプロキシで掛ける |
| HTTPS の受け口 | HTTP だけを話す | 前段のプロキシで HTTPS を受ける |
| 外部への転送を断るリダイレクト | `redirect().to()` は行き先を確かめない | 外から来た URL は自分で確かめる |
| 接続元を IPv4 の形にそろえる | `req.ip()` が `::ffff:10.0.0.1` の形で返ることがある | 比べる前に自分でそろえる |
| 信頼するプロキシの範囲指定（`10.0.0.0/8`） | 書けない。書くと警告して捨てる | アドレスを 1 つずつ並べる |
| ハンドラの引数を増やす仕組み（抽出子） | 引数の形は決まった 2 種類だけ | `req` から読む |
| HTTP クライアント | 無い | 好きなクレートを入れる |

### 入力の検査とセッション

| 項目 | いまどうなるか | 代わりにすること |
|------|----------------|------------------|
| 規則を型にまとめる（フォームリクエスト） | 無い | ハンドラの中に `req.validate` を書く |
| 検査の文面の差し替えと多言語 | 日本語で固定 | エラーの一覧から自分で組み立てる |
| セッションを DB や Redis に置く | ファイルとメモリだけ | 保存先を自分で書いて差し込む（[session.md](session.md)） |
| セッションに文字列以外を入れる | 入るのは文字列だけ | JSON の文字列にして入れる |
| 複数プロセスでのセッションの順番待ち | 1 プロセスの中だけ。違うと後から書いたほうが残る | 同じ利用者を同じプロセスへ送る |
| 1 回だけ使える CSRF トークン | 1 セッションに 1 つ（Laravel と同じ） | — |
| 署名付き URL の使い回しの検出 | 期限内なら何度でも使える | 使った印を自分で DB に残す |
| 複数プロセスで合算した回数の制限 | プロセスごとに数える。2 つなら上限は約 2 倍 | 前段のプロキシで掛ける |

### データベース

| 項目 | いまどうなるか | 代わりにすること |
|------|----------------|------------------|
| 副問い合わせ | 無い | `where_raw` で書く |
| `upsert` / `insert_or_ignore` | 無い | `DB::statement` で書く |
| `union` と行のロック | 無い | `DB::select` で書く |
| `where_not_like` / `or_where_null` / `right_join` / `cross_join` | 専用のメソッドが無い | `where_op`・`where_group`・`where_raw` で書く |
| 結果を少しずつ読む（ストリーム） | 結果は全件がメモリに載る | `limit` と `offset` で分ける |
| 一意制約以外のエラーの見分け | 見分けられるのは一意制約だけ | エラーの文を自分で見る |
| 読み用と書き用で接続を分ける | 無い | 名前付きの接続を使い分ける |
| 切れた接続へのやり直し | 無い | 呼ぶ側でやり直す |
| PostgreSQL の `uuid` / `money` / 配列を読む | 読めない | `cast(列 as text)` と書く |
| PostgreSQL の `timestamp` 列へ文字列を渡す | 渡せない | 列を `text` にするか、SQL で型を変える |
| PostgreSQL で同じ SQL を使い回す | 毎回、準備と実行の 2 往復になる | — |
| MySQL の文字コードと照合順序の指定 | サーバとデータベースの既定に従う | データベース側で決める |
| SQLite の値の数の上限を変える | 1 つの文に 32,766 個で固定 | 行を分けて入れる |
| 小数の末尾の 0 を保つ | 落ちる（`12.50` は `12.5`）。桁は落ちない | 表示のときに桁をそろえる |

### モデルとマイグレーション

| 項目 | いまどうなるか | 代わりにすること |
|------|----------------|------------------|
| 論理削除の自動の除外 | 列は作れるが、絞り込みは付かない | `where_null("deleted_at")` を書く |
| 変えた列だけを書き戻す | `save()` は作成日時以外の全列を書く | `DB::table(..).update(..)` を使う |
| 主キーを自分で決めた行を `save()` で入れる | 入らない | `DB::table(..).insert(..)` を使う |
| モデルの問い合わせでの `join` と数の増減 | 無い | `query_builder()` で降りて書く |
| モデルのイベント（`created` など） | 無い | `Event::dispatch` を自分で呼ぶ |
| ダミーデータの自動生成 | 無い | シーダーに連番で書く |
| 列の型を変える（`change()`） | できるのは列と索引の追加と削除まで | 新しい表を作って移す |
| 後から外部キーを足す | SQLite ではできない。警告して飛ばす | 表を作り直す |
| 後から主キーを足す | できない。警告して飛ばす | 表を作るときに指定する |
| シーダーを別の接続に流す | エラー。流せるのは既定の接続だけ | 既定の接続を切り替えて流す |
| `migrate:refresh --step=` | エラー | `migrate:rollback --step=` の後に `migrate` |
| SQL を流さずに見るだけ | 無い | `migrate:status` を見る |
| 複数の DB へまとめて流す | 無い | `--database=名前` で 1 つずつ流す |
| 複数のプロセスからの `migrate` の待ち合わせ | 後から来たほうは待たずに止まる | 1 か所から流す |

### 認証

| 項目 | いまどうなるか | 代わりにすること |
|------|----------------|------------------|
| Argon2 / bcrypt | PBKDF2 だけ（メモリを多く使う方式ではない） | 回数を上げて使う |
| ログインの口を複数持つ（guard） | セッション 1 つだけ | — |
| API 用のトークン認証 | 無い | ミドルウェアを自分で書く |
| メールアドレスの確認の一式 | 無い | 期限付きの署名付き URL で書く |
| パスワード再設定の画面とメール | あるのはトークンとリンクまで | 画面と `Mail` の送信を自分で書く |
| 再設定のトークンの期限を変える | 60 分で固定 | — |
| 再設定の再送を止める秒数を変える | 60 秒で固定 | — |
| `APP_KEY` の入れ替え | 手順が無い。替えると暗号文・署名・セッションが無効になる | 替える前に暗号文を戻しておく |
| 列の中身の自動の暗号化 | 無い | `encrypt` と `decrypt` を自分で呼ぶ |
| 長すぎるパスワードをエラーで知らせる | `Hash::make` はログに出すだけ | 検査で `max:1024` を掛ける |

### キャッシュ・ファイル・メール

| 項目 | いまどうなるか | 代わりにすること |
|------|----------------|------------------|
| Redis / Memcached のキャッシュ | ファイルとメモリだけ | 置き場所を自分で書いて差し込む（[cache.md](cache.md)） |
| DB にキャッシュを置く | 無い | — |
| キャッシュのタグ（`Cache::tags()`） | 無い | 鍵の頭をそろえる |
| キャッシュの錠（`Cache::lock()`） | 無い | — |
| `Cache::remember` の同時実行の防止 | 同時に来ると、作る処理が何回か走る | 重い処理は先に作っておく |
| S3 などの外部の置き場所 | `storage/` の下だけ | — |
| `Storage::url(パス)` | 無い | `/storage/` とパスをつなぐ |
| `/storage/` の頭を変える | 固定 | — |
| 名前が UTF-8 でないファイル | 一覧では警告して飛ばす | 名前を付け直す |
| メールの添付ファイル | 無い | リンクを本文に書く |
| 自己署名の証明書の SMTP サーバ | つながらない | 正規の証明書を使う |
| 送れなかったメールの再送 | 無い | キューに積んで、やり直しに任せる |
| `mail.log` の世代管理 | 増え続ける | 大きくなったら自分で消す |

### キュー・定期処理・イベント

| 項目 | いまどうなるか | 代わりにすること |
|------|----------------|------------------|
| Redis やファイルのキュー | DB の `jobs` 表だけ | — |
| ジョブのまとめ実行（`Bus::batch`） | 無い | — |
| 重複しないジョブ（`ShouldBeUnique`） | 無い | 積む前に自分で確かめる |
| ジョブごとの時間切れ | `--timeout` は worker 全体に効く | キューを分けて worker ごとに決める |
| 計算し続けるジョブの打ち切り | できない。止まらなければ失敗を記録して `queue:work` が終わる | 途中に待ちを挟む。worker は systemd などで立ち上げ直す |
| 失敗後の待ち時間を変える | 10 秒から倍々、320 秒までで固定 | — |
| ジョブの優先度と途中経過 | 無い | 優先度はキューを分ける |
| 複数のキューを 1 つの worker で処理 | 無い | `--queue=名前` ごとに worker を立てる |
| `queue:work` の自動の立ち上げ直し | DB の一時的なエラーだけ数回やり直す | systemd などに任せる |
| `queue:work` の停止待ちの上限 | いまの 1 件が終わるまで待つ | 2 回目の合図で強制終了する |
| 常駐するスケジューラ（`schedule:work`） | 無い | cron から 1 分ごとに `schedule:run` |
| 時刻の指定と cron の式 | 指定できるのは間隔だけ | 呼ぶ時刻を cron 側で決める |
| 1 分より細かい定期処理 | `Every::Seconds(n)` は `schedule:run` を呼ぶ間隔でしか動かない。登録時に警告 | 常駐する処理の中で回す |
| 定期処理の重なりの防止（`withoutOverlapping`） | 同時に呼ぶと両方で動く | 長い処理はキューに積む |
| 出来事の名前をまとめて受ける（`user.*`） | 無い | 名前を 1 つずつ登録する |
| 聞く側をキューで動かす | 無い | 聞く側から `Queue::push` を呼ぶ |

|------|----------------|------------------|

## 直っていない不ぞろい

動きがそろっていない所です。**直す予定ですが、まだ直っていません。**

| 項目 | いまどうなるか | 代わりにすること |
|------|----------------|------------------|
| 壊れた JSON を `req.json()` で読む | 500 になり、エラーのログも出る | 失敗を自分で 400 に変える |
| 空の入力を `get_as` で数に変える | `nullable` の項目が空だと 500 | `unwrap_or` で既定値を決める |
| JSON の入れ子を検査に渡す | 配列やオブジェクトは JSON の文字のまま検査される | `req.json()` で型に読む |
| 413・400・408 の応答 | エラーの見せ方を差し替えても通らない | — |
| 回数の制限に 0 回を渡す | `Throttle::new(0, ..)` は断られず、全部 429 | 1 以上を渡す |
| `log` のメールで `storage/logs/` が無い | 成功を返し、アプリのログにだけ出る | 先に `storage:init` を流す |
| `config/app.rs` が無いときの `APP_URL` | 既定は `http://localhost`。`init` の雛形は `http://localhost:8000` | `config/app.rs` を消さない |
| `about` の表示 | メールの行だけ設定の値。ほかは環境変数を直接読み、`config/` で変えた値は出ない | `config/` の中身を見る |
| 同じ型の設定を 2 つのファイルが返す | 知らせずに片方だけが残る | 設定の型はファイルごとに分ける |
| 整数の主キーに読めない文字列 | モデルの `find` と条件は 0 件。`DB::table` の条件は PostgreSQL で SQL エラー | 先に数に変えてから渡す |
| 大小の比較に `None` を渡す | エラーにならず、必ず 0 件 | `where_null` を使う |
| モデルの問い合わせで列を絞る | `select` の後の `get()` が「列がありません」で失敗 | `query_builder()` で降りて行で受ける |
| 採番しない表での `insert_get_id` | MySQL は行が入った後にエラー（文で知らせる）。SQLite は別の値（rowid）を返す | `insert` を使う |
| データベース名付きの表（`main.posts`）の索引 | SQLite では作れない。PostgreSQL の `drop index` は schema を付けない | 表名に `.` を付けない |
| 名前で選んだ接続の種類を聞く | `driver()` と表の一覧が、名前付きの接続に無い | 問い合わせを作ってから `driver()` を聞く |
| `logout_other_devices` と他の端末の切断が重なる | 同じミリ秒に重なったときだけ、呼んだ本人が残る | — |
| `Session::get` と `all()` の順 | 持ち越しの `flash` と `put` が同じ鍵だと、`get` は `flash`、`all()` は `put` を返す | 同じ鍵に両方を書かない |
| 切られたセッションの Cookie | ほかの端末から切られても、ブラウザには残る | 次のログインで置き換わる |
| ルートに当たらないリクエスト | Cookie があると、セッションを 1 回読む | — |
| `public/` の切れたリンクと読めないファイル | リリースビルドが落ちる。飛ばすのはディレクトリへのリンクだけ | 切れたリンクを置かない |
| `public/` の隠しファイル | 開発中は配られ、リリースビルドでは 404 | `.` で始まる名前を置かない |
| `jobs` 表が無いままの `queue:work` | `migrate` を案内せず、数回やり直して止まる | 先に `migrate` を流す |
| `Cache::increment` のエラーの文 | 渡した鍵ではなく、変換後の鍵が出ることがある | — |

## 直さないと決めた制限

直せますが、直さないと決めたものです。使うときに気をつけてください。

| 項目 | いまどうなるか | 代わりにすること |
|------|----------------|------------------|
| 回数の制限は 1 つの錠で数える | 1 つの制限に掛かるリクエストは 1 本ずつ順に数える | 負荷が高いときは前段のプロキシで掛ける |
| `queue:retry` は失敗ジョブを全件読む | 全件をメモリに載せる | 多いときは `--id` で選ぶ |
| `Storage::put` は途中で止まると残る | 書きかけのファイルが残ることがある | 大事なものは別名で書いてから移す |
| ファイル錠は OS のロックを使わない | 古い錠を外す一瞬だけ 2 者が錠を持てる（警告のログが出る）。途中で落ちると `+locks/` に `*.new.*` が残る | — |
| `Cache::increment` は期限を保たない | 期限なしで書き直す（Laravel と違う） | 期限が要るなら `put` で書き直す |
| メモリのキャッシュはプロセスの中だけ | ほかのプロセスからは見えない | 共有するなら `file` を使う |
| `select` には式を書ける | 文字列がそのまま SQL に入る | 外から来た文字列を渡さない |
| 設定に無い接続名での `to_sql()` | SQLite の形で組み立てる。流すとエラー | 接続名を確かめる |
| `insert_get_id_as` の主キーの指定 | SQL に入るのは PostgreSQL だけ | 採番する列を指定する |
| `db:seed` を 2 回流すと失敗する | メールアドレスが重なる（Laravel も同じ） | `migrate:fresh --seed` を使う |
| `migrate` の札は手で外す | 途中で落ちると札（実行中の印）が残り、次が止まる | `migrate:unlock` を流す |
| DB を使うテストは順番に走る | 同時には走らない | — |
| 開発中のログインが数秒かかる | パスワードの変換を 12 万回くり返すため | 開発中は `.env` で回数を下げる |
| `serve` の反映は最大 0.65 秒遅れる | 一定の間隔で見に行くため | — |
| `serve` は数と更新時刻だけを見る | ファイルの数と、いちばん新しい更新時刻だけ | 反映されないときは保存し直す |
| `serve` はビルド中の `Cargo.lock` の変更を見落とす | ビルド自身の書き換えと区別できない | `serve` を立ち上げ直す |
| `serve` は本体をすぐ止める | 停止の猶予（`APP_SHUTDOWN_TIMEOUT`）は通らない | 猶予を見るときは本体を直接動かす |
| 切断されたリクエストは待たない | 処理は続くが、停止の待ち合わせから外れる | 停止の上限時間で打ち切られる |
| 合図の直後の 2 回目は届かないことがある | 1 回目の直後の一瞬だけ。プロセスは落ちない | もう 1 回送る |
| `key:generate` は持ち主を引き継がない | 権限は引き継ぐ。持ち主は流した人になる | 流した後で持ち主を戻す |
| `init`・`list`・`help`・`--version` の余分な引数 | 無視する | — |
| 基準のディレクトリは `cargo` の値が先 | `.env` や `storage/` の有無は確かめない | 本番は `APP_BASE_PATH` で指定する |
| `sqlite` などを入れると依存が増える | SQL を扱うクレートが入る | 要らないときは機能フラグを外す |
| 一覧の表の桁そろえ | 半角 1・全角 2 と数えるだけ。ずれる文字がある | `--json` があればそちらを使う |
| ディレクトリをたどる深さ | 32 段まで。超えた分は警告して飛ばす | 浅く置く |
| 配信の中継（`database`）は 5 秒より遅いコミットを取りこぼすことがある | 書いた時刻から 5 秒たった行は読み直さない。それより遅れてコミットされた行は届かない | `publish` はトランザクションの外で、すぐ終わる形で呼ぶ |
| 配信の中継はプロセスどうしの時計がそろっている前提 | 書いた側の時計で時刻を入れ、読む側の時計で 5 秒を数える。大きくずれると取りこぼす | サーバーの時計を NTP（時刻合わせ）でそろえる |
| 配信の中継は、最初に表を読めた時点から届ける | 表（`broadcasts`）が無いままサーバーを起動すると、表ができる前に書かれた行は届かない | マイグレーションを流してからサーバーを起動する |
| 配信の `memory` はプロセスの中だけ | ほかのプロセスの接続には届かない | `BROADCAST_CONNECTION=database` にする |
| `Broadcast::local_count` はプロセスの中だけ | サーバーが複数なら、ほかのプロセスの接続を数えない | 合計が要るなら、アプリが DB などで数える |
| `serve` の作り直しで WebSocket が切れる | 本体をすぐ止めるので Close も送らない | クライアントをつなぎ直す形にする |

## 作らないと決めたもの

**これからも作りません。** 使うときに関わるものだけを載せます。
理由は [decisions.md](decisions.md) にあります。

### HTTP と入力の検査

| 項目 | 代わりにすること |
|------|------------------|
| テンプレート（Blade に当たるもの） | `html(...)` に文字列を渡すか、JSON を返す |
| `Route::resource()` | 7 行を手で書く |
| グループの設定を内側で外す（`withoutMiddleware()`） | 外したいルートをグループの外に出す |
| URL を作るときの `{{` での `{` の逃がし方 | `{` は必ずパス引数の始まり。パスに `{` を使わない |
| 必要なものを外から渡す仕組み（サービスコンテナ） | `DB::` などの入口から使う。登録は `bootstrap/app.rs` |
| 正規表現の検査（`regex:`） | ハンドラの中で確かめる |
| DB を見る検査（`unique` / `exists`） | `exists()` の問い合わせを書く（[database.md](database.md)） |
| 配列と入れ子の項目名（`tags[]` / `user.name`） | `req.json()` で型に読む |
| セッションの中身の暗号化 | 中身はブラウザに出ない |
| どこからでも読める `Auth::user()` | `req` から読む |
| 実行中の設定の書き換え | 設定は起動時に固まる |

### データ

| 項目 | 代わりにすること |
|------|------------------|
| SQL Server / Oracle | SQLite・MySQL・MariaDB・PostgreSQL を使う |
| 表の名前の推測 | `#[model(table = "posts")]` と必ず書く |
| リレーションの宣言（`hasMany` など） | `impl` にただのメソッドを書く |
| まとめ読み（`with()`）と遅延ロード | `where_in` で 2 回に分けて読む（[models.md](models.md)） |
| 属性の型の変換（`$casts`） | 構造体の型で決める |
| 日時の専用の型 | 文字列で扱う |
| 引数の型からモデルを自動で読む | `req.model::<Post>("post").await?` と書く |
| `#[derive(Model)]` での文字列の主キー | `Model` を手で実装する |
| `update` と `delete` への `join` や `limit` | エラーになる。条件で絞る |
| `group_by` と合計・平均の併用 | エラーになる。`select` に式を書く |

### 認証

| 項目 | 代わりにすること |
|------|------------------|
| ログイン状態を覚える Cookie | セッションの期限を長くする |
| 認証画面の生成 | 自分で書く |
| 外部サービスでのログインと 2 段階の確認 | 専用のクレートを使う |
| 役割と権限の表 | 関数の中で条件を書く |
| 権限の登録表（`Gate::define`） | `app/Policies/` に関数を書く |
| 権限の確認を非同期で書く | 先に読んでから、同期の関数に渡す |

### 周辺機能

| 項目 | 代わりにすること |
|------|------------------|
| 通知（Notification） | `Mail` を直接使う |
| Pusher 互換のプロトコル（Laravel Reverb と Echo） | アプリが自分のやり取りの形を決める |
| チャンネルの認可の仕組み（`routes/channels.php`） | 切り替える前に確かめ、`join` するかをアプリが決める |
| 配信の再送のための履歴と連番 | 取りこぼしを埋めたいなら、アプリが連番を持つ |
| WebSocket の圧縮（permessage-deflate） | CPU と遅れを増やすので使わない |
| HTTP/2 の上の WebSocket | bengara は HTTP/1.1 だけを話す |
| Redis などの外部の中継 | Redis を持たない。DB の表（`database`）で中継する |
| メールのテンプレートと Markdown | `format!` で組み立てる |
| イベントのクラスと購読者 | 名前は文字列、聞く側は関数にする |
| 聞く側の自動登録（`app/Listeners/`） | `bootstrap/app.rs` に書く |
| 言語ファイルの実行時の読み込み | ビルドし直す |
| JSON 形式の言語ファイル | TOML で書く |
| 実行中の既定のディスクの切り替え | `Storage::disk(名前)` で選ぶ |

### コマンドと運用

| 項目 | 代わりにすること |
|------|------------------|
| `make:*` の生成コマンド | ファイルを手で作る |
| tinker（対話シェル） | —（Rust はコンパイルしてから動くので作れない） |
| コマンドの `$signature` の文法 | 渡された文字列を読む |
| 自作コマンドの進捗バー | `println!` で出す |
| `storage:link` | `/storage/...` がそのまま配信される |
| `optimize`（設定のキャッシュ） | 要らない。設定は起動時に固まる |
| `down`（メンテナンスモード） | 前段のプロキシで止める |
| `migrate` の札の自動解除（時間切れ） | `migrate:unlock` を流す |
| 無停止での入れ替えの自動化 | 手順は [deployment.md](deployment.md) |
| 内蔵の負荷分散 | 前段のプロキシに任せる |
| 独自の停止コマンド | プロセスに停止の合図を送る |
| systemd のソケットからの起動 | 普通にポートを開く |
