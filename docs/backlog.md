# まだ無いもの

**まだ無い機能と、知っておくべき制限は、このページだけに書きます。**
いま使えるものは [README.md](README.md) の各ページにあります。

| 節                                            | 中身                                 |
|-----------------------------------------------|--------------------------------------|
| [まだ無い機能](#まだ無い機能)                 | これから作るかもしれないもの         |
| [直っていない所](#直っていない所)             | 動きがそろっていない所。直す予定     |
| [直さないと決めた制限](#直さないと決めた制限) | 直せるが、直さないと決めたもの       |
| [作らないと決めたもの](#作らないと決めたもの) | これからも作らないもの               |
| [確かめていない環境](#確かめていない環境)     | まだ動かしていない OS とデータベース |

- 表は「項目 → いまどうなるか → 代わりにすること」の順です。
- 「代わりに」が「—」のものは、いまは手がありません。
- 「前段のプロキシ」は、bengara の前に置く nginx などのことです。

## まだ無い機能

### ルートとミドルウェア

| 項目                                           | いまどうなるか                 | 代わりにすること                  |
|------------------------------------------------|--------------------------------|-----------------------------------|
| `Route::any` / `match` / `options`             | 書けるのは 5 つのメソッドだけ  | メソッドごとに 1 行ずつ書く       |
| パス引数の後ろの固定文字（`/posts/{id}.json`） | 登録できない                   | `/posts/{id}/json` と区切る       |
| 1 区間に 2 つのパス引数（`/{year}-{month}`）   | 登録できない                   | `/{year}/{month}` に分ける        |
| サブドメインでの振り分け                       | 見るのはパスだけ               | 前段のプロキシで振り分ける        |
| ミドルウェアへの引数（`throttle:60,1`）        | 渡せるのは名前だけ             | 設定済みのものを別名で登録する    |
| ミドルウェアの優先順の指定                     | 登録した順と書いた順に通る     | 並べる順で調整する                |
| 既定のミドルウェアの組（Laravel の `web`）     | 無い                           | `bootstrap/app.rs` に自分で並べる |
| 内側のエラーの中身をミドルウェアで見る         | 見えるのは出来上がった応答だけ | ステータスで見分ける              |
| ルートの一覧をテストから取る                   | 取る口が無い                   | `routes/web.rs` を読む            |
| グループに本文の上限を付ける                   | `.max_body` はルートごとだけ   | ルートに 1 つずつ付ける           |
| CORS（別のサイトからの呼び出しの許可）         | 無い。`OPTIONS` は 405         | 前段のプロキシで付ける            |

### リクエストとレスポンス

| 項目                                         | いまどうなるか                                   | 代わりにすること                                                   |
|----------------------------------------------|--------------------------------------------------|--------------------------------------------------------------------|
| ファイルのアップロード（multipart 形式）     | 読めない                                         | 本文をそのまま受けて保存する（`.stream_body()` と `write_stream`） |
| 少しずつ届く本文の、全体の時間と最低の速さ   | 見るのは「次のかたまりが 30 秒来ない」だけ       | 前段のプロキシで掛ける                                             |
| 大きなファイルを少しずつ返す                 | 全部をメモリに読んでから返す                     | 前段のプロキシで配る                                               |
| 途中からの取得（`Range`）と `Last-Modified`  | 無い。`ETag` と 304 はある                       | 前段のプロキシで配る                                               |
| 圧縮済みのファイル（gzip / brotli）          | 無い                                             | 前段のプロキシで圧縮する                                           |
| 接続の待ち時間と同時接続数の上限             | 無い                                             | 前段のプロキシで掛ける                                             |
| HTTPS で受ける                               | HTTP だけを話す                                  | 前段のプロキシで HTTPS を受ける                                    |
| 外のサイトへの転送を断る                     | `redirect().to()` は行き先を見ない               | 外から来た URL は自分で確かめる                                    |
| 接続元を IPv4 の形にそろえる                 | `req.ip()` が `::ffff:10.0.0.1` の形のことがある | 比べる前に自分でそろえる                                           |
| 信頼するプロキシを範囲で書く（`10.0.0.0/8`） | 書くと警告して捨てる                             | アドレスを 1 つずつ並べる                                          |
| ハンドラの引数を増やす仕組み（抽出子）       | 引数の形は決まった 2 種類だけ                    | `req` から読む                                                     |
| HTTP クライアント（外へ要求を送る道具）      | 無い                                             | 好きなクレートを入れる                                             |

### 入力の検査とセッション

| 項目                                                       | いまどうなるか                                         | 代わりにすること                                         |
|------------------------------------------------------------|--------------------------------------------------------|----------------------------------------------------------|
| 検査の文面の差し替えと多言語                               | 日本語で固定                                           | エラーの一覧から自分で組み立てる                         |
| 検査の前の権限の確認（FormRequest の `authorize()`）       | 無い。`FormRequest` が持つのは規則だけ                 | ハンドラで `authorize(..)?` を先に呼ぶ                   |
| 検査の `url` でホスト名の形まで見る                        | 見るのは方式・ホストの有無・使えない文字・ポートだけ   | `starts_with` などと組み合わせる                         |
| セッションを DB や Redis に置く                            | ファイルとメモリだけ                                   | 保存先を自分で書いて差し込む（[session.md](session.md)） |
| セッションに文字列以外を入れる                             | 入るのは文字列だけ                                     | `put_json` / `get_json` で JSON にして入れる             |
| 複数プロセスでのセッションの順番待ち                       | 1 プロセスの中だけ。後から書いたほうが残る             | 同じ利用者を同じプロセスへ送る                           |
| 1 回だけ使える CSRF トークン（成りすまし送信を防ぐ合言葉） | 1 セッションに 1 つ（Laravel と同じ）                  | —                                                        |
| 署名付き URL の使い回しを見抜く                            | 期限内なら何度でも使える                               | 使った印を自分で DB に残す                               |
| 回数の制限を複数プロセスで合算する                         | プロセスごとに数える。2 つなら上限は約 2 倍            | 前段のプロキシで掛ける                                   |
| IPv6 の接続元を `/64` でまとめて数える                     | アドレス 1 つずつ数える                                | 前段のプロキシで掛ける                                   |
| 回数の制限をグループで 1 つの枠にする                      | ルートごとに数える                                     | —                                                        |
| `.stream_body()` の間も、同じ人のほかの要求を通す          | 受け取りが終わるまで待たせる                           | —                                                        |
| 「切った」セッションの印を、要求の始まりから数える         | とても長く走る要求は、切られたセッションを保存し直せる | —                                                        |
| `session:gc` がコードで決めた期限を知る                    | `SESSION_LIFETIME` だけを見る                          | 期限は `.env` で決める                                   |

「とても長く」は、1 時間とセッションの期限の長いほうより長い、という意味です。

### テンプレート

| 項目                                                  | いまどうなるか                                    | 代わりにすること                                    |
|-------------------------------------------------------|---------------------------------------------------|-----------------------------------------------------|
| 検査に落ちた理由をテンプレートで出す（`$errors`）     | テンプレートに `errors` が無い                    | —                                                   |
| フォームの `_method` での読み替え（`@method('PUT')`） | 読み替えない                                      | POST のルートで受ける                               |
| エラーページをテンプレートで作る（`errors/404.html`） | エラーの画面はテンプレートから作らない            | —                                                   |
| メールの本文のテンプレート                            | `Mail` にテンプレートの名前を渡せない             | `bengara::view::render` の結果を `.html(..)` に渡す |
| 全テンプレートの構文を確かめるコマンド                | 確かめるのはリリースビルドの `serve` の起動時だけ | テンプレートを描くテストを書く                      |

### データベース

| 項目                                                             | いまどうなるか                                         | 代わりにすること                              |
|------------------------------------------------------------------|--------------------------------------------------------|-----------------------------------------------|
| 副問い合わせ（問い合わせの中の問い合わせ）                       | 無い                                                   | `where_raw` で書く                            |
| `upsert` / `insert_or_ignore`                                    | 無い                                                   | `DB::statement` で書く                        |
| `union` と行のロック                                             | 無い                                                   | `DB::select` で書く                           |
| `where_not_like` / `or_where_null` / `right_join` / `cross_join` | 専用のメソッドが無い                                   | `where_op`・`where_group`・`where_raw` で書く |
| 結果を少しずつ読む（ストリーム）                                 | 全件がメモリに載る                                     | `limit` と `offset` で分ける                  |
| 一意制約以外のエラーの見分け                                     | 見分けられるのは一意制約だけ                           | エラーの文を自分で見る                        |
| 接続の失敗の原因を種類で見分ける                                 | 原因はエラーの文に入るだけ                             | エラーの文を自分で見る                        |
| `having_op` で `select` の別名を使う                             | 使えない                                               | `having_raw` で書く                           |
| 読み用と書き用で接続を分ける                                     | 無い                                                   | 名前付きの接続を使い分ける                    |
| 切れた接続へのやり直し                                           | 無い                                                   | 呼ぶ側でやり直す                              |
| PostgreSQL の `uuid` / `money` / 配列を読む                      | 読めない                                               | `cast(列 as text)` と書く                     |
| PostgreSQL の `timestamp` 列へ文字列を渡す                       | 渡せない                                               | 列を `text` にするか、SQL で型を変える        |
| PostgreSQL で同じ SQL を使い回す                                 | 毎回、準備と実行の 2 往復                              | —                                             |
| `distinct` 付きの `paginate` を、どの列の組でも数える            | 名前が重なりうる形（`posts.*` とほかの列など）はエラー | 列を絞るか、`group_by` で書く                 |
| MySQL の文字コードと照合順序の指定                               | サーバとデータベースの既定に従う                       | データベース側で決める                        |
| SQLite の値の数の上限を変える                                    | 1 つの文に 32,766 個で固定                             | 行を分けて入れる                              |
| 小数の末尾の 0 を保つ                                            | 落ちる（`12.50` は `12.5`）。桁は落ちない              | 表示のときに桁をそろえる                      |
| ページ分けの JSON に `last_page`・`from`・`to`                   | JSON には入らない。メソッドはある                      | `last_page()` などを読んで自分で足す          |

### モデルとマイグレーション

| 項目                                         | いまどうなるか                      | 代わりにすること                             |
|----------------------------------------------|-------------------------------------|----------------------------------------------|
| 論理削除（消した印を付けるだけ）の自動の除外 | 列は作れるが、絞り込みは付かない    | `where_null("deleted_at")` を書く            |
| 変えた列だけを自動で書き戻す                 | `save()` は作成日時以外の全列を書く | `save_only(&[列])` で書く列を選ぶ            |
| 主キーを自分で決めた行を `save()` で入れる   | 入らない                            | `DB::table(..).insert(..)` を使う            |
| モデルの問い合わせでの `join` と数の増減     | 無い                                | `query_builder()` で降りて書く               |
| モデルのイベント（`created` など）           | 無い                                | `Event::dispatch` を自分で呼ぶ               |
| ダミーデータの自動生成（factory）            | 無い                                | シーダーに連番で書く                         |
| 外部キーを名前で落とす（`drop_foreign`）     | 無い                                | `schema.raw(..)` で `drop constraint` を書く |
| 列の型を変える（`change()`）                 | できるのは列と索引の追加と削除まで  | 新しい表を作って移す                         |
| 後から外部キーを足す（SQLite）               | できない。警告して飛ばす            | 表を作り直す                                 |
| 後から主キーを足す                           | できない。警告して飛ばす            | 表を作るときに指定する                       |
| 列のコメント（`comment()`）                  | 受け付けるが、SQL には出ない        | `schema.raw(..)` で書く                      |
| SQLite で索引の付いた列を落とす              | 失敗する                            | 先に `drop_index` で索引を落とす             |
| シーダーを別の接続に流す                     | エラー。流せるのは既定の接続だけ    | 既定の接続を切り替えて流す                   |
| `migrate:refresh --step=`                    | エラー                              | `migrate:rollback --step=` の後に `migrate`  |
| SQL を流さずに見るだけ（`--pretend`）        | 無い                                | `migrate:status` を見る                      |
| 複数の DB へまとめて流す                     | 無い                                | `--database=名前` で 1 つずつ流す            |
| 複数のプロセスからの `migrate` の待ち合わせ  | 後から来たほうは待たずに止まる      | 1 か所から流す                               |
| 日時のタイムゾーン                           | `Carbon` は UTC だけ                | 表示するときに自分で時差を足す               |
| 日時の書式の指定（`format('Y/m/d')`）        | 無い                                | `to_date_string()` などの決まった形を使う    |
| 「3 日前」の形（`diff_for_humans`）          | 無い                                | `diff_in_days` などで自分で組み立てる        |

### 認証

| 項目                                            | いまどうなるか                                          | 代わりにすること                     |
|-------------------------------------------------|---------------------------------------------------------|--------------------------------------|
| パスワードの方式 bcrypt（Laravel の `$2y$`）    | 照合できない。偽になる                                  | パスワードの再設定で作り直してもらう |
| ログインの口を複数持つ（guard）                 | セッション 1 つだけ                                     | —                                    |
| API 用のトークン認証                            | 無い                                                    | ミドルウェアを自分で書く             |
| メールアドレスの確認の一式                      | 無い                                                    | 期限付きの署名付き URL で書く        |
| パスワード再設定の画面とメール                  | あるのはトークンとリンクまで                            | 画面と `Mail` の送信を自分で書く     |
| 再設定のトークンの期限を変える                  | 60 分で固定                                             | —                                    |
| 再設定の再送を止める秒数を変える                | 60 秒で固定                                             | —                                    |
| `APP_KEY` の入れ替えの手順                      | 無い。替えると暗号文・署名・セッションが無効になる      | 替える前に暗号文を戻しておく         |
| 列の中身の自動の暗号化                          | 無い                                                    | `encrypt` と `decrypt` を自分で呼ぶ  |
| 長すぎるパスワードをエラーで知らせる            | `Hash::make` はログに出すだけ                           | 検査で `max:1024` を掛ける           |
| 照合の時間をそろえる回数を下げる                | 覚えた最大の回数は、起動し直すまで下がらない            | 起動し直す                           |
| 方式と強さを 1 つの設定にまとめる（0.2 の予定） | 方式は `HASH_DRIVER`、強さは `ArgonConfig` で別に決める | —                                    |

### キャッシュ・ファイル・メール

| 項目                                            | いまどうなるか                                       | 代わりにすること                                       |
|-------------------------------------------------|------------------------------------------------------|--------------------------------------------------------|
| Redis / Memcached のキャッシュ                  | ファイルとメモリだけ                                 | 置き場所を自分で書いて差し込む（[cache.md](cache.md)） |
| DB にキャッシュを置く                           | 無い                                                 | —                                                      |
| キャッシュのタグ（`Cache::tags()`）             | 無い                                                 | 鍵の頭をそろえる                                       |
| キャッシュの錠（`Cache::lock()`）               | 無い                                                 | —                                                      |
| `Cache::remember` の同時実行の防止              | 同時に来ると、作る処理が何回か走る                   | 重い処理は先に作っておく                               |
| 自作の置き場所の `increment` の排他             | 既定の実装は読んで足して書くだけ。同時に呼ぶとずれる | `increment` を自分で実装する                           |
| S3 などの外部の置き場所                         | `storage/` の下だけ                                  | —                                                      |
| ファイルの URL を作る（`Storage::url`）         | 無い                                                 | `/storage/` とパスをつなぐ                             |
| `/storage/` の頭を変える                        | 固定                                                 | —                                                      |
| 名前が UTF-8 でないファイル                     | 一覧では警告して飛ばす                               | 名前を付け直す                                         |
| 打ち切った `write_stream` の書きかけ（Windows） | 消せずに残ることがある                               | 後で掃除する                                           |
| 確かめた直後のリンクの差し替えを防ぐ            | 防げない                                             | `storage/` にほかの人が書けないようにする              |
| メールの添付ファイル                            | 無い                                                 | リンクを本文に書く                                     |
| 自己署名の証明書の SMTP サーバ                  | つながらない                                         | 正規の証明書を使う                                     |
| 送れなかったメールの再送                        | 無い                                                 | キューに積んで、やり直しに任せる                       |
| `mail.log` の世代管理                           | 増え続ける                                           | 大きくなったら自分で消す                               |

### キュー・定期処理・イベント

| 項目                                                    | いまどうなるか                                                 | 代わりにすること                                       |
|---------------------------------------------------------|----------------------------------------------------------------|--------------------------------------------------------|
| Redis やファイルのキュー                                | DB の `jobs` 表だけ                                            | —                                                      |
| ジョブのまとめ実行（`Bus::batch`）                      | 無い                                                           | —                                                      |
| 重複しないジョブ（`ShouldBeUnique`）                    | 無い                                                           | 積む前に自分で確かめる                                 |
| ジョブごとの試す回数と待ち時間（`$tries` / `$backoff`） | `--tries` は worker 全体に効く                                 | キューを分けて worker ごとに決める                     |
| 失敗後の待ち時間を変える                                | 10 秒から倍々、320 秒までで固定                                | —                                                      |
| `retry_after` と `tries` を `config/queue.rs` に書く    | `queue:work` の旗（`--retry-after` / `--tries`）だけ           | 旗で渡す                                               |
| `Queue::ready_size` で、取り直せる古い予約も数える      | 数えない                                                       | —                                                      |
| 計算し続けるジョブの打ち切り                            | できない。失敗を記録して `queue:work` が終わる                 | 途中に待ちを挟む。worker は systemd などで立ち上げ直す |
| ジョブの優先度と途中経過                                | 無い                                                           | 優先度はキューを分ける                                 |
| 複数のキューを 1 つの worker で処理                     | 無い                                                           | `--queue=名前` ごとに worker を立てる                  |
| `queue:work` の自動の立ち上げ直し                       | DB の一時的なエラーだけ数回やり直す                            | systemd などに任せる                                   |
| `queue:work` の停止待ちの上限                           | いまの 1 件が終わるまで待つ                                    | 2 回目の合図で強制終了する                             |
| 全部の worker を止め直す（`queue:restart`）             | 無い                                                           | worker ごとに停止の合図を送る                          |
| 常駐するスケジューラ（`schedule:work`）                 | 無い                                                           | cron から 1 分ごとに `schedule:run`                    |
| 時刻の指定と cron の式                                  | 指定できるのは間隔だけ                                         | 呼ぶ時刻を cron 側で決める                             |
| 1 分より細かい定期処理                                  | `Every::Seconds(n)` は `schedule:run` を呼ぶ間隔でしか動かない | 常駐する処理の中で回す                                 |
| 定期処理の重なりの防止（`withoutOverlapping`）          | 同時に呼ぶと両方で動く                                         | 長い処理はキューに積む                                 |
| イベントの名前をまとめて受ける（`user.*`）              | 無い                                                           | 名前を 1 つずつ登録する                                |
| 聞く側をキューで動かす                                  | 無い                                                           | 聞く側から `Queue::push` を呼ぶ                        |

### 外部コマンド（`Process`）

| 項目                                         | いまどうなるか                                   | 代わりにすること                                       |
|----------------------------------------------|--------------------------------------------------|--------------------------------------------------------|
| 裏で走らせて後で待つ（`start()`）            | `run` で終わりを待つだけ                         | 待たずに画面を返すなら、ジョブの中で `run` を呼ぶ      |
| まとめて走らせる（`pool`）・つなぐ（`pipe`） | 無い                                             | 1 つずつ `run` を呼ぶ。つなぐなら `["sh", "-c", ".."]` |
| 出力が止まったら打ち切る（`idleTimeout`）    | 打ち切るのは全体の時間（`timeout`）だけ          | —                                                      |
| 端末を引き継ぐ（`tty`）                      | 無い                                             | —                                                      |
| テストで差し替える（`Process::fake()`）      | 無い                                             | 起動する部分を関数に分ける                             |
| 出力を逐次受け取る                           | 終わってから全部まとめて返す。全部メモリに溜まる | 多いなら `quietly()` で捨てるか、ファイルに書かせる    |

| 書き口を返す `Storage::writer(パス)`                     | かたまりごとに `append_bytes`、本文なら `write_stream`          |

### コマンドと運用

| 項目                                 | 代わりにすること                               |
|--------------------------------------|------------------------------------------------|
| `make:*` の生成コマンド              | ファイルを手で作る                             |
| tinker（対話シェル）                 | —（Rust はコンパイルしてから動くので作れない） |
| コマンドの `$signature` の文法       | 渡された文字列を読む                           |
| 自作コマンドの進捗バー               | `println!` で出す                              |
| `storage:link`                       | 要らない。`/storage/...` がそのまま配られる    |
| `optimize`（設定のキャッシュ）       | 要らない。設定は起動時に固まる                 |
| `down`（メンテナンスモード）         | 前段のプロキシで止める                         |
| `migrate` の札の自動解除（時間切れ） | `migrate:unlock` を流す                        |
| 無停止での入れ替えの自動化           | 手順は [deployment.md](deployment.md)          |
| 内蔵の負荷分散                       | 前段のプロキシに任せる                         |
| 独自の停止コマンド                   | プロセスに停止の合図を送る                     |
| systemd のソケットからの起動         | 普通にポートを開く                             |
